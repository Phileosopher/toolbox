
# Tools for Lisp and its dialects

## Specific dialects

### Common Lisp

[awesome-cl](https://github.com/CodyReichert/awesome-cl)

GNU implementation:  
[GCL](https://www.gnu.org/software/gcl/)

Implementations:  
[awesome-cl-software](https://github.com/azzamsa/awesome-cl-software)

Learning:  
[CLISP - an ANSI Common Lisp Implementation](https://www.gnu.org/software/clisp/),
[Learn Common Lisp](https://lisp-lang.org/learn/),
[Practical Common Lisp](https://gigamonkeys.com/book/)

Specifications:  
[LispWorks' Common Lisp HyperSpec](http://clhs.lisp.se/)

### Julia

Reactive programming environment:  
[Pluto.jl](https://plutojl.org/) ([GitHub](https://github.com/JuliaPluto/Pluto.jl))

### Racket

Learning:  
[The Racket Reference](https://docs.racket-lang.org/reference/),

Learning - macros:  
[Fear of Macros](https://www.greghendershott.com/fear-of-macros/)

### Scheme

GNU implementation:  
[MIT/GNU Scheme](https://www.gnu.org/software/mit-scheme/)

Learning:  
[The Scheme Programming Language, 4th Edition](https://www.scheme.com/tspl4/)

Learning - Chez Scheme dialect:  
[Chez Scheme](https://cisco.github.io/ChezScheme/) ([GitHub](https://github.com/cisco/ChezScheme))
